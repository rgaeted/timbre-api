# RIDE / PDF con timbre visual Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Generate RIDE (Representación Impresa del Documento Electrónico) PDF with embedded PDF417 barcode during document issuance, persist to database, and expose via GET endpoint.

**Architecture:** New `cl.timbre.pdf.RideBuilder` generates PDF (openpdf) with layout matching spec (header, receptor, detail lines, references for NC, totals, footer with PDF417), encodes TED as barcode via zxing. Integration into `IssuanceService` via separate try/catch — PDF generation failure does not block document emission. Interim storage in `Document.pdfContent` (BYTEA column) until phase D brings real S3/R2 storage.

**Tech Stack:** openpdf 2.0.3, zxing-core 3.5.3, zxing-javase 3.5.3 (already in pom.xml, unused)

## Global Constraints

- Supported document types: tipoDte 33 (Factura), 61 (Nota de Crédito) only
- PDF page size: Letter (8.5" × 11")
- TED encoding for PDF417: ISO-8859-1 (matches TedBuilder signing)
- Error handling: PDF generation failures log but do NOT block emission; document persists with pdfContent=null, estado=PENDIENTE_ENVIO
- No automatic retry for failed PDF generation (deferred to future phase)
- Multi-page support for detail lines: 2+ pages if needed, repeat table header

public static byte[] build(DteDocument dte, Element ted, Emisor emisor, LocalDateTime timestamp) {
    try (java.io.ByteArrayOutputStream baos = new java.io.ByteArrayOutputStream()) {
        com.lowagie.text.Document doc = new com.lowagie.text.Document(
            com.lowagie.text.PageSize.LETTER,
            36, 36, 60, 36  // left, right, top, bottom margins
        );
        com.lowagie.text.pdf.PdfWriter.getInstance(doc, baos);
        doc.open();

        // Header: emisor on left, document type box on right
        addHeader(doc, dte, emisor);
        
        // Receptor details
        addReceptor(doc, dte);
        
        // Detail table
        addDetailTable(doc, dte);
        
        // References (if NC)
        if (dte.tipoDte() == 61) {
            addReferences(doc, dte);
        }
        
        // Totals
        addTotals(doc, dte);
        
        // Footer with PDF417
        addFooter(doc, ted, emisor);

        doc.close();
        return baos.toByteArray();
    } catch (Exception e) {
        throw new RuntimeException("Failed to generate RIDE PDF", e);
    }
}

private static void addFooter(com.lowagie.text.Document doc, Element ted, Emisor emisor) throws com.lowagie.text.DocumentException {
    // Encode TED as PDF417
    byte[] tedBytes = cl.timbre.xml.XmlUtil.serialize(ted).getBytes(java.nio.charset.StandardCharsets.ISO_8859_1);
    com.google.zxing.BarcodeFormat format = com.google.zxing.BarcodeFormat.PDF_417;
    com.google.zxing.MultiFormatWriter writer = new com.google.zxing.MultiFormatWriter();
    com.google.zxing.BitMatrix matrix = writer.encode(
        java.util.Base64.getEncoder().encodeToString(tedBytes),
        format, 120, 60
    );
    
    // Convert BitMatrix to BufferedImage
    java.awt.image.BufferedImage image = new java.awt.image.BufferedImage(
        matrix.getWidth(), matrix.getHeight(), java.awt.image.BufferedImage.TYPE_INT_RGB
    );
    for (int x = 0; x < matrix.getWidth(); x++) {
        for (int y = 0; y < matrix.getHeight(); y++) {
            image.setRGB(x, y, matrix.get(x, y) ? java.awt.Color.BLACK.getRGB() : java.awt.Color.WHITE.getRGB());
        }
    }
    
    // Embed image in PDF
    com.lowagie.text.Image barcodeImg = com.lowagie.text.Image.getInstance(image, null);
    barcodeImg.setWidth(120);
    barcodeImg.setHeight(60);
    
    com.lowagie.text.Paragraph footerContainer = new com.lowagie.text.Paragraph();
    footerContainer.add(barcodeImg);
    footerContainer.setAlignment(com.lowagie.text.Element.ALIGN_CENTER);
    doc.add(footerContainer);
    
    com.lowagie.text.Paragraph timbreText = new com.lowagie.text.Paragraph("Timbre Electrónico SII", PdfUtils.normalFont(8));
    timbreText.setAlignment(com.lowagie.text.Element.ALIGN_CENTER);
    doc.add(timbreText);
    
    com.lowagie.text.Paragraph resText = new com.lowagie.text.Paragraph(
        "Res. " + emisor.getResolucionNumero() + " de " + emisor.getResolucionFecha().getYear(),
        PdfUtils.normalFont(8)
    );
    resText.setAlignment(com.lowagie.text.Element.ALIGN_CENTER);
    doc.add(resText);
}

public final class PdfUtils {

        return font;
    }
    
    public static Font normalFont(int size) {
        Font font = FontFactory.getFont(FontFactory.HELVETICA, size);
        font.setColor(0, 0, 0);
        return font;
    }
    
    public static String formatMoney(int cents) {
        // Convert cents to CLP string: 119000 cents = $119.000
        long pesos = cents;
        return String.format("$%,d", pesos).replace(",", ".");
    }
}

```java
@GetMapping("/{id}/pdf")
public ResponseEntity<?> pdf(@PathVariable String id) {
    Emisor emisor = EmisorContext.current();
    Document doc = documentRepository.findByIdAndEmisorId(id, emisor.getId())
            .orElseThrow(() -> new ApiException(HttpStatus.NOT_FOUND, "documento_no_encontrado",
                    "Documento no encontrado"));
    
    if (doc.getPdfContent() == null) {
        throw new ApiException(HttpStatus.CONFLICT, "pdf_no_disponible",
                "El PDF no está disponible. La generación falló durante la emisión.");
    }
    
    return ResponseEntity.ok()
            .contentType(org.springframework.http.MediaType.APPLICATION_PDF)
            .body(doc.getPdfContent());
}
```
